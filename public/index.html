Push webhook Add this URL as a push webhook in the repository settings with the secret below; every push to the branch queues a re-index.
Notion webhook — optional Edits, deletions and moves reach the index in seconds instead of waiting for the interval. It does not notice a page unshared from the integration — Notion sends no event for that — so keep the interval switched on. The endpoint has to be reachable from the internet over HTTPS.

Confluence webhook — optional, off until you turn it on Page edits, moves and deletions start a sync without waiting for the interval — within the minimum webhook interval, since a burst of deliveries is collapsed into one run. Blog posts are not indexed, so their events are ignored. It does not notice everything — a delivery Confluence gave up on, a page that became unreadable to this account without an event, or deliveries Confluence skips for up to hours after repeated failures all go unseen until the next scheduled sync — so keep the interval switched on. Deliveries must be signed with the secret below in X-Hub-Signature, which is what Confluence Data Center's own webhooks (Administration → Webhooks) do; Confluence Cloud has no built-in equivalent. The endpoint has to be reachable from Confluence.

Every run is held to the instance's crawl ceilings — pages, depth, the gap between requests, a total time budget and robots.txt (WEB_* in .env). Reaching one stops the run and says so on the source.

A vault is a folder of Markdown files. Drop the vault folder (or a zip of it) below; [[wikilinks]] are rewritten to Markdown links and .obsidian/ is skipped. If the vault is mounted on the server, add it as a Local directory with content type Obsidian vault instead.

File types
Everything but Markdown is converted to Markdown when it is indexed. A PDF that is a scan of paper has no text to convert and is reported on the source instead of indexed empty. The last three are read only by the OpenAPI content type, which turns one specification into one document per endpoint; a .yaml that is not a specification is reported on the source.
