Cookie Policy

Last updated: 18 September 2026

Contextator sets no cookies. Not for sessions, not for preferences, not for analytics. There is nothing to consent to, which is why you are not being asked.

1. What is used instead

The dashboard keeps one value in your browser's localStorage, and only when the server is protected by an admin token:

KeyPurposeLifetimeCategory
contextator_admin_token Holds the admin token you typed so the dashboard can send it as an Authorization header on every request instead of asking again on each page load. Until you clear the site data or the dashboard removes it after the token is rejected. Strictly necessary

localStorage is not a cookie: it is never attached to requests automatically, it is readable only by pages from this same origin, and it is not sent to any third party. The token is transmitted only to this server, on requests you trigger.

2. How to remove it

Clear site data for this origin in your browser settings, or use a private window. The dashboard will ask for the token again the next time it needs one. Nothing else about your visit is remembered.

3. No tracking

There are no analytics scripts, no tracking pixels, no advertising identifiers, no session recording and no third-party cookies set by us — in the dashboard, on these pages, or on contextator.com.

4. Third-party requests

The dashboard and these pages load typefaces from Google Fonts (fonts.googleapis.com and fonts.gstatic.com). Those requests are made by your browser to Google, which receives your IP address and user agent; the Fonts API is not used to set cookies, but the request itself does leave your machine. An operator who wants a fully self-contained installation can download the two font families and serve them from public/ instead.

Beyond that, the pages load nothing from anywhere else: no CDN scripts, no embedded players, no social widgets.

5. Changes

If cookies are ever introduced — they are not planned — this page will say so before they are set, and the date at the top will change. See the Privacy Policy for what the software stores on the server side.
